# RGC syntax highlighting for GTK Source View (gedit, GNOME Text Editor)

Copy `rgc.lang` into:

- gedit (gtksourceview 3): `~/.local/share/gtksourceview-3.0/language-specs/`
- GNOME Text Editor (gtksourceview 4): `~/.local/share/gtksourceview-4/language-specs/`
- or the corresponding system-wide `.../language-specs/` directory

Restart gedit / GNOME Text Editor. `.rg` files are highlighted automatically.
